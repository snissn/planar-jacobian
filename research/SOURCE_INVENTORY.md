# Source Inventory to Audit

The following names/topics recur in the conversations. This is a search inventory, not a bibliography.

| Area | Named source family | Required check |
|---|---|---|
| low degree | Orevkov; Domrina; Żołądek | geometric vs topological degree, exact upper bound |
| boundary normalization | Gurjar–Miyanishi | boundary components, singularities, affine-line fibrations |
| one-boundary models | Wright | ring presentation, simple-polynomial theorem, unresolved cases |
| irreducible fibers | Kaliman | exact reduction statement |
| group actions | Miyanishi; Regeta | finite groups, affine Lie algebra, integration hypotheses |
| nonproperness | Jelonek | asymptotic set and covering complement |
| compactification | Borisov and related work | boundary graphs, Stein factorization, numerical frameworks |
| monogenicity | modern schemes of monogenic generators | local openness and transition behavior |
| affine-plane fibrations | Kraft–Russell and related results | local triviality over curves and hypotheses |
| T-varieties | Altmann–Hausen | graded/polyhedral-divisor encoding |

Populate stable citations only after reading the primary source.
