# Countermodels and Explicit Mutation Tests

These examples test intermediate algebraic lemmas. None is asserted to be a
Keller map. The strongest example is proved in full in
`KELLER-NEAR-COUNTERMODEL.md`; the remaining models isolate individual local,
Galois, singular-fiber, and mutation phenomena.

## 1. Countermodel hierarchy

The models establish increasingly sharp negative controls.

| Model | Connected | Normal | Smooth | Rational | Locally monogenic everywhere | Fixed sheet at branch | Open `A2` | Source etale |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| diagonal cubic | yes | yes | not needed | no | yes | no | no claim | no |
| corank-two cubic | yes | yes | no | yes | no at one point | no | no claim | no |
| biquadratic cover | yes | yes | yes | yes | no at one point | no | `Y=A2` | no |
| fixed-sheet cubic | yes | yes | yes | yes | yes | yes | yes | **no** |

The last row leaves source etaleness as the first missing Keller-specific
property.

## 2. Strongest model: smooth rational fixed-sheet cubic

Let `B=C[u,v]` and let `O` have basis `1,w,e` with

```text
w^2=w-u e,
we=-uv,
e^2=v(w-1).                                               (2.1)
```

The complete proof is in `KELLER-NEAR-COUNTERMODEL.md`. Its load-bearing
formulas are

```text
Phi(x,y)=-(u x^3+x^2y+v y^3),                               (2.2)
Disc(O/B)=-v(4+27u^2v).                                     (2.3)
```

The opens `D(u)`, `D(v)`, and `D(1+u+v)` are generated by `w`, `e`, and
`w+e`, respectively. Nevertheless, the equation

```text
u x^3+x^2y+v y^3 in C*
```

has no polynomial solution. Setting `u=0` would give

```text
y_0(x_0^2+v y_0^2) in C*,
```

forcing a nonconstant linear polynomial to be a square.

The discriminant is squarefree. At `v=0`, the generic cubic is
`T^2(T-1)`; at `4+27u^2v=0`, it is
`(T-2/3)^2(T+1/3)`. Thus every branch component has one ramified double
sheet and one unramified sheet.

For every `lambda in C`,

```text
alpha_lambda=w+lambda e,
ind(alpha_lambda)=-(u+lambda+lambda^3v).                     (2.4)
```

The line in (2.4) is not a branch component, so `alpha_lambda` generates all
ramified height-one semilocalizations but has a nonempty unramified index
divisor. Distinct `lambda` give distinct lines.

The surface contains an open affine plane with coordinates `u,s`, on which

```text
(u,s) |-> (u,us^3-s^2),
J=s(3us-2).
```

The open immersion exists, but this open plane is not etale over the target.

## 3. A diagonal cubic: local but not global monogenicity

Let

```text
B=C[t,v],
d=t^2+1,
```

and let `O` have basis `1,w,e` with

```text
w^2=-t e,
e^2=d w,
we=-td.                                                       (3.1)
```

Over `K=Frac(B)`, one has

```text
e=-w^2/t,
w^3=t^2d.
```

The `t`-adic valuation of `t^2d` is two, so it is not a cube. The generic
algebra is a degree-three field and `O` is a domain.

Before adjoining the independent variable `v`, the local rings over `t=0`
and over the factors of `d` are explicit DVRs. Away from those primes the
trace discriminant is a unit. Hence `O` is normal. The underlying curve field
has genus two, so this model intentionally does not test rationality.

On `D(t)`, `O` is generated by `w`; on `D(d)`, it is generated by `e`.
Since `(t,d)=1`, these opens cover the base. Every element is

```text
alpha=c+xw+ye
```

and its index determinant is

```text
Phi(x,y)=-(t x^3+d y^3).                                     (3.2)
```

No value of (3.2) is a nonzero constant. As a polynomial in `t`, the two
possible leading degrees are congruent to one and two modulo three, so their
highest terms cannot cancel to degree zero.

The trace discriminant and power-basis discriminant are

```text
Disc(O/B)=-27t^2d^2,
Disc(1,alpha,alpha^2)=-27t^2d^2(t x^3+d y^3)^2.              (3.3)
```

An element is adapted at every ramified height-one prime exactly when its
index polynomial is coprime to `td`. Every adapted element still has a
nonempty index divisor at unramified generic points.

For

```text
alpha_lambda=w+lambda e,
lambda in C*,
```

one gets

```text
t+lambda^3(t^2+1)=0.                                        (3.4)
```

The divisor moves with `lambda^3`. Thus parameters differing by a cube root
of unity give the same divisor; parameters with distinct cubes give distinct
divisors. This corrects the stronger, false wording that every distinct
nonzero parameter gives a distinct divisor.

For arbitrary `h in B`,

```text
ind(w+h e)=-(t+d h^3),
```

which is never a unit. Because every polynomial expression reduces to a
unique `c+xw+ye`, the obstruction is exhaustive.

## 4. Rational normal corank-two model

Let `B=C[u,v]` and use

```text
w^2=-u e,
e^2=v w,
we=-uv.                                                       (4.1)
```

Embed the algebra in `C(u,s)` by

```text
v=u s^3,
w=u s,
e=-u s^2.
```

Then

```text
O=C[u,us,us^2,us^3].                                         (4.2)
```

The exponent semigroup

```text
{(a,b) in Z^2 : a>=0 and 0<=b<=3a}
```

is saturated, so the ring is normal. Its fraction field is `C(u,s)`, and it
is finite flat of rank three over `B`.

The exact formulas are

```text
Phi(x,y)=-(u x^3+v y^3),
Disc(O/B)=-27u^2v^2.                                         (4.3)
```

At the origin,

```text
O/(u,v)O=C+Cw+Ce,
(w,e)^2=0.
```

The maximal ideal of this special fiber has embedding dimension two, so the
fiber is not monogenic. This is the requested corank-two obstruction. The
element `w+e` generates every ramified height-one localization but has the
unramified index line `u+v=0`.

This model shows that rationality plus ramification adaptation is
insufficient. It lacks local monogenicity at the origin and the Keller
etale-source package.

## 5. Biquadratic Galois collision model

Let

```text
O=C[a,b],
B=C[u,v],
u=a^2,
v=b^2.
```

This is a finite flat normal rank-four Galois algebra with group
`(Z/2)^2`. For `c in C*`, put

```text
theta_c=a+c b.
```

Its four sheet values are

```text
a+cb, a-cb, -a+cb, -a-cb.
```

The Vandermonde, normal discriminant, and power-basis index are

```text
V(theta_c)=64c^2uv(u-c^2v),                                  (5.1)
Disc(O/B)=2^8u^2v^2,                                         (5.2)
ind(theta_c)=-4c^2(u-c^2v).                                  (5.3)
```

Thus

```text
V(theta_c)^2=Disc(O/B) ind(theta_c)^2.
```

The factors `uv` are intrinsic ramification. The remaining line
`u=c^2v` is an accidental collision divisor and moves with the parameter.
At the origin the fiber is `C[a,b]/(a^2,b^2)`, of embedding dimension two,
so no single element generates it.

This example shows that a Galois closure and globally labeled sheets do not
turn fiberwise generic separation into global divisorial separation.

## 6. Semilocal factor collision

Let `A` be a DVR with uniformizer `pi` and put

```text
S=A x A,
alpha=(0,pi).
```

Each projection of `A[alpha]` to a factor is surjective, but

```text
A[alpha]={(a,b): a=b mod pi} != S.
```

Thus generation must be tested on the whole semilocal algebra `O_p`, not
separately on each localization `O_q` above `p`.

## 7. Tame non-Galois local model

Let

```text
k=C(s),
A=k[[pi]],
g(Z)=Z^3-Z-s.
```

The polynomial `g` is irreducible over `k`, and its discriminant
`4-27s^2` is not a square. Put `E=k(beta)` with `g(beta)=0`, and let

```text
S=E[[tau]],
pi=tau^2,
alpha=beta+tau.
```

Modulo `pi`, one has `tau^2=0` and

```text
g(alpha)=g'(beta)tau.
```

Because `g'(alpha)` is a unit, `tau` lies in `k[bar(alpha)]`; then so does
`beta`. Hence

```text
k[bar(alpha)]=E[tau]/(tau^2)=S/pi S,
```

and Nakayama gives `A[alpha]=S`. This is a tame, non-Galois example with
mixed residue degree and ramification index, confirming that the semilocal
DVR generator lemma is not a Galois artifact.

## 8. Exact negative implications

The models refute the following statements as purely algebraic lemmas:

```text
normal + finite flat + locally monogenic everywhere
  => globally monogenic;
```

```text
one element generates every ramified height-one semilocalization
  => its index divisor is empty;
```

```text
generic separability or distinct values on one fiber
  => no divisorial sheet collision;
```

```text
smooth + rational + squarefree tame branch + fixed sheets
+ an open affine plane
  => globally monogenic.
```

They do not refute the Keller-specific bridge. The strongest model fails
exactly because its displayed open affine plane is not etale over the target.
A rescue must use the constant-Jacobian/etale-source condition to force a
unit value of the universal index form.
