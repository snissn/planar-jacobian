The examples in this file are countercontrols for intermediate algebraic lemmas. They are not asserted to arise from Keller maps. Their purpose is to isolate exactly which additional Keller-specific hypothesis a successful moving-index argument must use.

## 1. A normal rank-three algebra that is locally but not globally monogenic

Let

```text
B = C[t,v],
d = t^2+1,
```

and let `O` be the free `B`-module with basis `1,w,e` and multiplication

```text
w^2 = -t e,
e^2 = d w,
w e = -t d.                                               (1.1)
```

The displayed multiplication is associative. For example,

```text
(w^2)e = -t e^2 = -t d w = w(we),
(we)e  = -t d e = w(e^2),
```

and the remaining checks follow by commutativity and bilinearity.

### 1.1 Domain and generic field

Over `K=Frac(B)`, relation (1.1) gives

```text
e = -w^2/t,
w^3 = t^2 d.
```

The element `t^2d` is not a cube in `K`: its `t`-adic valuation is `2`, which is not divisible by `3`. Since `K` contains the cube roots of unity, `T^3-t^2d` is irreducible. Hence

```text
O tensor_B K = K(w)
```

is a field of degree three, and `O` is a domain.

### 1.2 Normality

It is enough to prove normality before adjoining the independent variable `v`. Put `B_0=C[t]` and `O_0=B_0+ B_0w+B_0e`.

At the prime `(t)`, `d` is a unit and

```text
w=e^2/d,
e^3=-t d^2.
```

Thus `(O_0)_(t)=B_{0,(t)}[e]`; its maximal ideal is generated by `e`, because `t=-e^3/d^2`. It is a one-dimensional regular local ring, hence a DVR.

At either prime dividing `d`, the element `t` is a unit and

```text
e=-w^2/t,
w^3=t^2d.
```

Again the local ring is generated by one uniformizer `w`, so it is a DVR.

The trace discriminant computed in the basis `1,w,e` is

```text
disc(O_0/B_0) = -27 t^2 d^2.                              (1.2)
```

At every other prime this is a unit, so the localized algebra is finite etale and therefore normal. Hence `O_0` is normal. Polynomial extension preserves normality, so

```text
O=O_0[v]
```

is a normal finite-flat `B`-algebra.

The curve field `C(t,w)` is not rational. The degree-three map to the `t`-line is totally ramified over `t=0`, `t=i`, `t=-i`, and `t=infinity`; Riemann--Hurwitz gives

```text
2g-2 = 3(-2)+4(3-1)=2,
```

so `g=2`. Thus this first countermodel deliberately tests local monogenicity rather than the rational Keller package.

### 1.3 Zariski-local monogenicity on the entire base

On `D(t)`, relation (1.1) gives `e=-w^2/t`, and therefore

```text
O_t=B_t[w].
```

On `D(d)`, it gives `w=e^2/d`, and therefore

```text
O_d=B_d[e].
```

Because `(t,d)=B`, the opens `D(t)` and `D(d)` cover `Spec(B)`. Thus `O/B` is Zariski-locally monogenic everywhere.

The transition between these two primitive elements is quadratic:

```text
e=-w^2/t,
w=e^2/d.
```

It is not affine-linear, so the affine-transition restricted theorem does not apply.

### 1.4 The exact index form

Every element of `O` has a unique expression

```text
alpha = c+xw+ye,
```

with `c,x,y in B`. Translation by `c` does not affect the generated order. In the basis `1,w,e`, the determinant of the power basis `1,alpha,alpha^2` is

```text
Phi(x,y) = -(t x^3+d y^3).                                 (1.3)
```

Consequently,

```text
B[alpha]=O  <=>  t x^3+d y^3 is in C*.                     (1.4)
```

No such `x,y` exist. Regard the expression as a polynomial in `t` with coefficients in `C[v]`. If `x` and `y` are both nonzero, then

```text
deg_t(t x^3) = 1 mod 3,
deg_t(d y^3) = 2 mod 3.
```

The highest terms cannot cancel. If one of `x,y` vanishes, the remaining term still has positive `t`-degree. Therefore `Phi(x,y)` is never a nonzero constant. The algebra is not globally monogenic.

This proves:

> A connected normal finite-flat algebra over the affine plane can be locally monogenic on a Zariski cover of the entire base, while admitting no global primitive integral generator.

### 1.5 Ramification adaptation forces an accidental etale collision divisor

By (1.2), the ramification support is

```text
V(t d).
```

The local index criterion and (1.3) show that `alpha=c+xw+ye` generates at the ramified prime `(t)` exactly when

```text
y notin (t),
```

and it generates at each prime dividing `d` exactly when

```text
x notin (t-i) and x notin (t+i).
```

For every such ramification-adapted element,

```text
gcd(t x^3+d y^3, t d)=1,
```

but `t x^3+d y^3` is a nonunit. Hence it has a nonempty height-one zero divisor whose generic points lie in the finite etale locus. Every ramification-adapted element therefore acquires accidental unramified index support.

### 1.6 Moving divisors under mutation

For every `lambda in C*`, take

```text
alpha_lambda = w+lambda e.
```

Its index equation is

```text
t+lambda^3(t^2+1)=0.                                       (1.5)
```

It is adapted at every ramified prime, but the nonempty collision divisor moves with `lambda`. Distinct nonzero values of `lambda` give distinct divisors.

More generally, for `h in B`,

```text
alpha_h=w+h e,
Phi(alpha_h)=-(t+d h^3).                                   (1.6)
```

The same degree argument shows that (1.6) is never a unit. Allowing a polynomial coefficient moves or reshapes the divisor; it does not remove it. Since every polynomial expression in any set of generators reduces to `c+xw+ye`, formula (1.3) is exhaustive rather than an artifact of a narrow mutation ansatz.

### 1.7 Discriminant verification

The trace Gram matrix in the basis `1,w,e` is

```text
[ 3       0        0    ]
[ 0       0      -3td   ]
[ 0     -3td       0    ],
```

so its determinant is `-27t^2d^2`. The power-basis discriminant is

```text
disc(1,alpha,alpha^2)
  = -27t^2d^2 (t x^3+d y^3)^2,                             (1.7)
```

which is exactly the normal discriminant times the square of the index form.

## 2. A rational normal rank-three corank-two model

Rationality by itself does not repair the bridge. Let

```text
B=C[u,v]
```

and let `O` be free with basis `1,w,e` and relations

```text
w^2=-u e,
e^2=v w,
w e=-uv.                                                   (2.1)
```

Embed it in `C[u,s]` by

```text
v=u s^3,
w=u s,
e=-u s^2.                                                (2.2)
```

Then

```text
O = C[u,us,us^2,us^3].                                    (2.3)
```

The exponent semigroup is

```text
{(a,b) in Z^2 : a>=0 and 0<=b<=3a},
```

which is saturated in its lattice. Hence the semigroup ring (2.3) is normal. Its fraction field is

```text
Frac(O)=C(u,s),
```

so it is rational. It is finite flat of rank three over `B`, with basis `1,w,e`.

The same determinant computation gives

```text
Phi(x,y)=-(u x^3+v y^3),                                   (2.4)
disc(O/B)=-27u^2v^2.                                       (2.5)
```

Every value of (2.4) lies in the maximal ideal `(u,v)`, so there is no global generator. On `D(u)` the algebra is generated by `w`; on `D(v)` it is generated by `e`. The only missing base point is the origin.

At the origin,

```text
O/(u,v)O = C + Cw+Ce,
(w,e)^2=0.                                                  (2.6)
```

Its maximal ideal has embedding dimension two. A subalgebra generated by one element has dimension at most two, so the special fiber is not monogenic. This is the exact corank-two obstruction.

The element `w+e` generates every ramified height-one localization, while its index divisor is

```text
u+v=0,
```

whose generic point is unramified. Thus a rational function field plus ramification adaptation is still insufficient. What is missing is the Keller open immersion and etaleness on that specified affine-plane source.

Geometrically, (2.3) is the third Veronese surface ring

```text
C[a^3,a^2b,ab^2,b^3]
```

after setting `u=a^3` and `s=b/a`; the origin is the cyclic quotient singularity responsible for (2.6).

## 3. A biquadratic Galois collision model

Let

```text
O=C[a,b],
B=C[u,v],
u=a^2,
v=b^2.
```

Then `O/B` is finite flat normal of rank four with Galois group `(Z/2)^2`. For `c in C*`, put

```text
theta_c=a+c b.
```

Its four sheet values are

```text
a+cb, a-cb, -a+cb, -a-cb.
```

Their Vandermonde product is

```text
V(theta_c)=64 c^2 u v (u-c^2v).                            (3.1)
```

In the normal basis `1,a,b,ab`,

```text
disc(O/B)=2^8u^2v^2,                                       (3.2)
```

while the power-basis inclusion determinant is

```text
ind(theta_c)=-4c^2(u-c^2v).                                (3.3)
```

Equations (3.1)--(3.3) satisfy `V^2=disc(O) ind^2` exactly.

The intrinsic factors `uv` record ramification. The remaining factor

```text
u-c^2v
```

is an accidental sheet-collision divisor. It is disjoint from the ramification divisors at its generic point and moves with `c`. In particular, a generic constant linear combination separates one fiber but still has a global divisorial collision.

At the origin the special fiber is

```text
C[a,b]/(a^2,b^2),
```

which has embedding dimension two and cannot be generated by one element: the powers of any element span at most `1,alpha,alpha^2`, a space of dimension at most three rather than four.

This example is intentionally Galois. It shows that labeling sheets globally does not improve the genericity argument; the collision hyperplanes remain.

## 4. A tame non-Galois local model

The simultaneous ramification-adaptation theorem does not depend on Galois symmetry. Let

```text
k=C(s),
A=k[[pi]],
g(Z)=Z^3-Z-s.
```

The polynomial `g` is irreducible over `k`: the rational map `z |-> z^3-z` has degree three. Its discriminant `4-27s^2` is not a square in `k`, so the residue extension

```text
E=k(beta),  g(beta)=0,
```

is non-Galois.

Put

```text
S=E[[tau]],
pi=tau^2.
```

This is a tame extension with residue degree three and ramification index two. Set

```text
alpha=beta+tau.
```

Modulo `pi`, one has `tau^2=0` and

```text
g(alpha)=g'(beta)tau.
```

The element `g'(alpha)` is a unit in `k[alpha]`, and division by it recovers `tau`; then `beta=alpha-tau`. Thus

```text
k[bar(alpha)]=E[tau]/(tau^2)=S/pi S.
```

Nakayama gives

```text
A[alpha]=S.
```

This is a concrete tame, non-Galois instance of the semilocal DVR lemma.

## 5. What these models refute, and what they do not

The examples refute the following purely algebraic implications:

```text
local monogenicity on the entire base
  + normality
  + finite flatness
  + factorial base
  => global monogenicity;
```

```text
one element generates every ramified height-one localization
  => its index divisor is empty;
```

```text
generic separability or distinct values on one fiber
  => no divisorial sheet collisions;
```

```text
rational function field
  + ramification adaptation
  => global monogenicity.
```

They do **not** refute the Keller-specific statement, because none supplies the full simultaneous package

```text
L=C(x,y),
A2_source openly immersed in Y,
Y -> A2_target finite,
A2_source -> A2_target etale,
O subset C[x,y].
```

Any rescue of the route must consume that package in a way that rules out the index forms (1.3) and (2.4), or proves an equivalent global support theorem.
