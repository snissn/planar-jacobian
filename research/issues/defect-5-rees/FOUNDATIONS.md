## 2. Weighted layers and missing degrees

Let `R=C[x,y]`, with `deg_w(x)=p`, `deg_w(y)=q`, and let `R_d` be the
weighted-homogeneous piece of degree `d`; set `R_d=0` for `d<0`. Write

```text
P=sum_(i>=0) P_i,  P_i in R_(d_P-i),
Q=sum_(j>=0) Q_j,  Q_j in R_(d_Q-j).
```

A degree absent from the semigroup generated by `p,q` is represented by a zero
layer. This convention is used in every stair and every support table.

## 3. Rees identity

Define

```text
Pcal(t,x,y)=t^(d_P) P(t^(-p)x,t^(-q)y),
Qcal(t,x,y)=t^(d_Q) Q(t^(-p)x,t^(-q)y).
```

Then

```text
(Pcal)_x=t^(d_P-p) P_x(t^(-p)x,t^(-q)y),
(Pcal)_y=t^(d_P-q) P_y(t^(-p)x,t^(-q)y),
```

and similarly for `Qcal`. With

```text
J(f,g)=f_x g_y-f_y g_x,
```

both determinant products carry exponent

```text
(d_P-p)+(d_Q-q)=(d_P-q)+(d_Q-p)=kappa.
```

Therefore

```text
J(Pcal,Qcal)
=t^kappa J(P,Q)(t^(-p)x,t^(-q)y)
=t^kappa.                                            (F1)
```

Since `Pcal=sum_i t^i P_i` and `Qcal=sum_j t^j Q_j`, coefficient comparison
gives

```text
S_n:=sum_(i+j=n) J(P_i,Q_j)=delta_(n,kappa).         (F2)
```

Moreover

```text
J(P_i,Q_j) in R_(kappa-i-j).                         (F3)
```

The left side of (F1) is a polynomial in `t`, so `kappa>=0`. Terms with
`i+j>kappa` vanish individually by (F3). At resonance `i+j=kappa`, every
bracket is a scalar; their sum is one, so at least one is nonzero.

## 4. Defect-five stairs with signs fixed

For `kappa=5`, equations (F2) are exactly

```text
S_0 = J(P_0,Q_0)                                                   = 0,
S_1 = J(P_0,Q_1)+J(P_1,Q_0)                                      = 0,
S_2 = J(P_0,Q_2)+J(P_1,Q_1)+J(P_2,Q_0)                           = 0,
S_3 = J(P_0,Q_3)+J(P_1,Q_2)+J(P_2,Q_1)+J(P_3,Q_0)                = 0,
S_4 = J(P_0,Q_4)+J(P_1,Q_3)+J(P_2,Q_2)+J(P_3,Q_1)+J(P_4,Q_0)   = 0,
S_5 = J(P_0,Q_5)+J(P_1,Q_4)+J(P_2,Q_3)+J(P_3,Q_2)
      +J(P_4,Q_1)+J(P_5,Q_0)                                     = 1.
```

No term is dropped merely because a different resonant term was selected for
normalization. A missing layer is zero; a simultaneously nonzero resonant
bracket remains in `S_5` with the displayed sign.
