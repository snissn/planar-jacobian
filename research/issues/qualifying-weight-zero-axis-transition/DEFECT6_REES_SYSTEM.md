# Complete Defect-Six Rees Systems

## 1. Universal staircase

For

```text
P=sum_i P_i,  Q=sum_j Q_j,
kappa_w=d_P+d_Q-p-q=6,
```

the Rees identity is

```text
J(sum_i t^i P_i, sum_j t^j Q_j)=t^6.
```

Coefficient comparison gives all seven equations:

```text
S_0 = J(P_0,Q_0) = 0,
S_1 = J(P_0,Q_1)+J(P_1,Q_0) = 0,
S_2 = J(P_0,Q_2)+J(P_1,Q_1)+J(P_2,Q_0) = 0,
S_3 = J(P_0,Q_3)+J(P_1,Q_2)+J(P_2,Q_1)+J(P_3,Q_0) = 0,
S_4 = J(P_0,Q_4)+J(P_1,Q_3)+J(P_2,Q_2)
      +J(P_3,Q_1)+J(P_4,Q_0) = 0,
S_5 = J(P_0,Q_5)+J(P_1,Q_4)+J(P_2,Q_3)
      +J(P_3,Q_2)+J(P_4,Q_1)+J(P_5,Q_0) = 0,
S_6 = J(P_0,Q_6)+J(P_1,Q_5)+J(P_2,Q_4)+J(P_3,Q_3)
      +J(P_4,Q_2)+J(P_5,Q_1)+J(P_6,Q_0) = 1.
```

The following lists contain every weighted-homogeneous monomial in each layer.
Constants and zero layers are displayed even though their derivatives vanish.
Coefficients `A,B,c` are declared nonzero.

## 2. Normal form I

```text
(m,n)=(2,3),  (a,b)=(3,3),  w=(1,3),  rho=2.
```

Complete layers:

```text
P_0=A x^4,
P_1=u x^3+v y,
P_2=r x^2,
P_3=x,
P_4=alpha,
P_5=0,
P_6=0;

Q_0=B x^6,
Q_1=e x^5+f x^2 y,
Q_2=g x^4+h x y,
Q_3=c y,
Q_4=k x^2,
Q_5=ell x,
Q_6=beta.
```

After collecting only identical exponent vectors:

```text
S_0: 0.

S_1: 4 A f-6 B v=0.

S_2: 4 A h-5 v e+3 u f=0,
     -2 v f=0.

S_3: 4 A c-4 v g+3 u h+2 r f=0,
     -v h=0.

S_4: 3 c u+2 r h+f=0.

S_5: 2 c r-2 v k+h=0.

S_6: c-v ell=1.
```

The contradiction is forced before the constant-bracket layer is used:
`v f=0` and `4Af-6Bv=0` give `v=f=0`; then `h=0`; then `4Ac=0`, contrary to
`A c!=0`.

## 3. Normal form II

```text
(m,n)=(2,3),  (a,b)=(5,1),  w=(1,8),  rho=3.
```

Complete layers:

```text
P_0=A x^6,
P_1=u_1 x^5,
P_2=u_2 x^4,
P_3=u_3 x^3,
P_4=u_4 x^2,
P_5=x,
P_6=alpha;

Q_0=B x^9,
Q_1=c y,
Q_2=v_2 x^7,
Q_3=v_3 x^6,
Q_4=v_4 x^5,
Q_5=v_5 x^4,
Q_6=v_6 x^3.
```

All brackets between pure `x` polynomials vanish. The stairs are

```text
S_0: 0,

S_3: 4 c u_2=0,
S_4: 3 c u_3=0,
S_5: 2 c u_4=0,
S_6: c=1.
```

`S_1` contradicts `A c!=0`.

## 5. Normal form IV

```text
(m,n)=(3,2),  (a,b)=(5,1),  w=(1,3),  rho=2.
```

Complete layers:

```text
P_0=A x^6,
P_1=u x^5+v x^2 y,
P_2=r x^4+s x y,
P_3=t x^3+z y,
P_4=h x^2,
P_5=x,
P_6=alpha;

Q_0=B x^4,
Q_1=c y,
Q_2=k x^2,
Q_3=ell x,
Q_4=beta,
Q_5=0,
Q_6=0.
```

The complete coefficient system is

```text
S_0: 0.

S_1: 6 A c-4 B v=0.

S_2: 5 c u-4 B s=0,
      2 c v=0.

S_3: 4 c r-4 B z-2 v k=0,
      c s=0.

S_4: 3 c t-v ell-2 s k=0.

S_5: 2 c h-s ell-2 z k=0.

S_6: c-z ell=1.
```

Since `c!=0`, the second `S_2` equation gives `v=0`; `S_1` then gives
`6Ac=0`, impossible.

## 6. Saturation statement

For each normal form, let `I` be the ideal generated by all coefficients in
`S_0,...,S_5,S_6-1`. The exact checker verifies

```text
I:(A B c)^infinity=(1).
```

It separately constructs all 16 raw source/component orientations and obtains
the unit ideal in each one. Thus the determinant-one normal-form reduction is
not being used to hide a sign, scalar, source-order, or component-order case.
