# Definitions and the Replacement Invariant

## 1. Keller pairs and weights

Work over `C`. A **normalized Keller pair** is

```text
F=(P,Q) in C[x,y]^2,
J(P,Q)=P_x Q_y-P_y Q_x=1.
```

A source weight is a primitive vector `w=(p,q)` with `p,q>0`. Put

```text
d_P(w)=max{p i+q j:(i,j) in Supp(P)},
d_Q(w)=max{p i+q j:(i,j) in Supp(Q)},
kappa_w(F)=d_P(w)+d_Q(w)-p-q.
```

Write weighted layers from the top as

```text
P=sum_i P_i,  deg_w P_i=d_P-i,
Q=sum_j Q_j,  deg_w Q_j=d_Q-j,
```

where an absent weighted degree means the zero polynomial. Define

```text
Pcal=t^d_P P(t^-p x,t^-q y),
Qcal=t^d_Q Q(t^-p x,t^-q y).
```

The chain rule gives exactly

```text
J(Pcal,Qcal)=t^kappa_w,
```

so `kappa_w` is a nonnegative integer and

```text
sum_(i+j=r) J(P_i,Q_j)=delta_(r,kappa_w).
```

No support is completed by convexity, genericity, or a missing-layer
convention other than literal zero.

## 2. Compensated transformations

Every polynomial automorphism of `A^2` has a nonzero constant Jacobian. A pair
`(alpha,beta)` of source and target automorphisms is **compensated** when

```text
J(alpha) J(beta)=1.
```

Then `beta o F o alpha` is again normalized Keller. An uncompensated source or
target scaling is not in the same transformation class.

The following classes are compared without silently taking unions.

### 2.1 `C_SL`

Source and target linear maps in `SL_2(C)`. There are no translations or
nonlinear operations.

### 2.2 `C_aff`

All compensated affine source and target automorphisms. Translations are
included. They do not change positive weighted top degrees but remain part of
the declared class.

### 2.3 `C_tri-tgt`

The identity source together with the target subgroup generated by
determinant-one shears

```text
(u,v)->(u,v-h(u)),
(u,v)->(u-h(v),v),
```

and the signed target swap `(u,v)->(v,-u)`. This class is not silently enlarged
to arbitrary source shears.

### 2.4 `C_gr(w)`

For one fixed weight `w`, source automorphisms whose pullback and inverse
pullback preserve every weighted filtration piece, paired with the required
target determinant compensation. These are the graded normalizations used in
the fixed-weight staircase.

### 2.5 `C_tame`

Compensated source and target automorphisms generated by affine and elementary
triangular automorphisms.

### 2.6 `C_full`

All compensated polynomial source and target automorphisms. Jung--van der Kulk
identifies `Aut_C C[x,y]` with the tame group, so `C_tame=C_full` as plane orbit
classes. This equality does not supply a descending factorization for an
unknown Keller pair.

## 3. Class-indexed orbit complexity

For any declared class `C` containing the identity compensated pair, define

```text
S_C(F)={kappa_w(beta o F o alpha):
        w primitive positive, (alpha,beta) in C},
mu_C(F)=min S_C(F).
```

### Proposition `QWD-MIN`

`mu_C(F)` exists and is achieved.

**Proof.** `S_C(F)` is nonempty because the identity and `w=(1,1)` are allowed.
Every member lies in `N` by the Rees identity applied to the transformed Keller
pair. Every nonempty subset of `N` has a least element, and that least element
is one of the achieved values because `S_C(F)` is an image set. No topology,
closure, compactness, or finite generation of the orbit is used. `square`

Different classes can give different values. The unqualified notation `mu(F)`
is therefore rejected in this packet.

## 4. Why the two scalar extremes are inadequate

For every polynomial automorphism `F` with `J(F)=1`,

```text
mu_full(F)=0,
```

because the target automorphism `F^-1` sends `F` to the identity. The scalar
therefore uses the inverse whose existence is the unknown conclusion when `F`
is only known to be Keller.

Conversely, [`TRANSFORMATION_ORBIT.md`](TRANSFORMATION_ORBIT.md) proves that
`mu_aff` and `mu_SL` are unbounded on explicit automorphisms. An affine-only
scalar is too rigid, while the full-orbit scalar is circular as a practical
descent detector.

## 5. Certified directed descent

A **certified descent step** is a triple `(G,w,G')` of normalized Keller pairs
and a primitive positive weight satisfying one of the following exact rules.

1. **Orientation/normalization.** A compensated affine or `w`-graded source
   normalization with an explicit polynomial inverse. No decrease is claimed.
2. **Complete-top target descent.** The top layers have

   ```text
   G_1,0=A H,
   G_2,0=B H^n
   ```

   or the transposed form, and a determinant-one target shear cancels the
   **entire** higher top layer. The actual defect is recomputed at the same
   weight and is strictly smaller.
3. **Equal-top linear descent.** Proportional complete top layers are cancelled
   by a determinant-one linear target operation, and the recomputed actual
   defect strictly decreases.

A partial monomial cancellation, a Laurent change, a completion-valued
Hamiltonian exponential, or a transformation that lowers a displayed term but
not the weighted degree is not a certified step.

Write `F =>_D G` for a finite chain of certified steps, allowing length zero.
This is directed rewriting, not an equivalence relation: the inverse of a
strictly decreasing shear is not automatically an allowed forward step.

## 6. Lexicographic directed complexity

For `G=(R,S)` and primitive positive `w`, set

```text
Lambda(G,w)=(
  kappa_w(G),
  deg(R)+deg(S),
  |Supp(R)|+|Supp(S)|,
  e_+(R)+e_+(S),
  2 Area(N(R)+N(S)),
  d_R(w)+d_S(w)
).
```

Here `e_+` counts compact Newton edges with a strictly positive outward normal.
Twice the area of a lattice polygon is a nonnegative integer and is defined to
be zero for a segment or point. Every coordinate lies in `N`.

Define

```text
nu_D(F)=min_lex {Lambda(G,w):F =>_D G,
                              w primitive positive}.
```

The set is nonempty, and finite lexicographic products of `N` are well-ordered,
so `nu_D(F)` exists. It records support cost after certified descents without
licensing an arbitrary inverse target automorphism.

## 7. Finite combinatorial core

Fix a minimizing value of `Lambda`. Its ordinary-degree coordinate bounds all
support exponents inside a finite degree triangle, and its support-cardinality
coordinate bounds the number selected. For each fixed support pair, the finite
fan theorem supplies finitely many candidate weights. Thus the coefficient-free
record

```text
Core_D(F)={
  (Supp(R),Supp(S),w,
   exposed faces, lattice edge lengths, coprime powers)
  attaining nu_D(F)
}
```

is finite. Coefficients can still vary in algebraic families. The claim is
finiteness of the combinatorial record, not finiteness of the automorphism orbit
or of all polynomial pairs.

## 8. Global minimal-counterexample universe

The contradiction program in
[`MINIMAL_COUNTEREXAMPLE.md`](MINIMAL_COUNTEREXAMPLE.md) uses a different
minimum. Assuming a noninvertible normalized planar Keller pair exists, it
minimizes `Lambda(G,w)` over **all** such pairs and all primitive positive
weights. Polynomial source and target automorphisms preserve noninvertibility,
so every transformed pair remains in that universe.

This global minimum yields stronger reduction statements than `nu_D` but is not
presented as a computable invariant of one starting pair.

## 9. Complete binomial-chain class

For `N>=2`, `B_N` consists of pairs

```text
P=a x+b y^N,
Q=c y+sum_(k=0)^N q_k x^k y^(N(N-k)),
a b c q_N !=0.
```

The complete coefficient calculation in
[`TRANSFORMATION_ORBIT.md`](TRANSFORMATION_ORBIT.md) proves that the Keller
condition forces `Q=c y+lambda P^N`. This is the named exact class used for the
primary scoped disposition.
