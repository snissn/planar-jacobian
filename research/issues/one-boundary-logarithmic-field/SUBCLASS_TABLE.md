## 1. Smooth target image

The smooth-target-image row is a classification of the requested semisimple
field, not a theorem that every smooth one-boundary model is impossible. If a
semisimple integral field existed, its action would linearize and the invariant
curve would have one of the forms

```text
u=0,
v=0,
u-cv^b=0,
u^a v^b-c=0.
```

Each form carries an actual target `G_m` action, so `OBLF-05` excludes it. A
smooth curve of positive genus, or a non-toric rational affine curve, can have
no such field; exact-symplectic equations must then do additional work.

## 2. Rational one-place branch

“One place at infinity” does not mean “smooth `A1`.” The cases are kept
separate.

- If the affine curve is smooth and isomorphic to `A1`, Abhyankar-Moh makes it
  a coordinate curve and the model is excluded.
- If it is the weighted cusp `P^a-Q^b`, the Euler action is conductor-compatible
  and the model is excluded.
- If it is singular and not semi-invariant under any target torus, no
  semisimple field is available. The conductor quotient and principal parts
  form the remaining finite system at each fixed numerical semigroup.

## 3. Weighted-homogeneous branch

The disposition is independent of smoothness. The weighted Euler field is a
nonzero semisimple integral logarithmic field. It integrates on the target,
lifts after finite isogeny, preserves the unique ramified boundary, and makes
the Keller map equivariant. The terminal theorem therefore forces empty
boundary.

## 4. Coordinate-line direct control

For `C={u=0}`, the complement is `A1 x G_m`. A connected degree-`d` finite
etale cover with one divisor above `u=0` has monodromy generated by a transitive
`d`-cycle. Equivalently the pullback divisor has

```text
div_Y(u)=d D0.
```

On `U=Y-D0`, the function `u` would be a nonconstant unit. Since
`C[x,y]^*=C*`, this is incompatible with `U=A2` unless the boundary is empty.
This gives an independent control for the coordinate-line row; the main proof
uses the torus theorem so that it also covers weighted and hyperbolic branches.

## 5. Exact overall disposition

The substantial named subclass result is:

```text
A generically ramified one-boundary Keller normalization cannot have a
G_m-invariant reduced branch curve.
```

The general smooth or generically smooth one-boundary model is narrowed to the
non-toric branch class and the finite compatibility system of `OBLF-09`. It is
not silently promoted to degree one.
