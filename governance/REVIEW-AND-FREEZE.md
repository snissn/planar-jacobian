# Review and Freeze Protocol

This repository follows the scientific-mainline discipline used in the referenced workflow and recent physics-repository work.

1. Construct on an issue-scoped feature branch.
2. Commit coherent non-decisive notes and source inventories as mutable provenance.
3. Keep any decision-bearing theorem/validator packet uncommitted until its exact bytes pass adversarial review.
4. Bind review to the base commit, exact path set, file hashes, hypotheses, claim scope, and validation evidence.
5. Freeze one coherent accepted artifact set.
6. Integrate only the reviewed set; preserve mutable branch provenance.
7. Separate engineering status, execution validity, protocol verdict, and scientific inference.

A repository validator or green CI run is not mathematical review.
