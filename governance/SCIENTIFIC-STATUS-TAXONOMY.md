# Scientific Status Taxonomy

Every artifact should distinguish:

- `authority`: mutable non-authoritative / reviewed freeze / mainline checkpoint;
- `engineering_status`: development / qualified / defect;
- `execution_validity`: not an execution / valid / invalid;
- `protocol_verdict`: null / pass / scoped failure / inconclusive;
- `scientific_inference`: exact statement and forbidden stronger inference.

Most files in this repository are analytic notes, not scientific executions.
